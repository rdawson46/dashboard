# LLM

A full-stack application that provides a interface powered by a local Large Language Model (LLM) using Ollama.
The application allows users to interact with the LLM through a chat-like interface.

## Tech Stack

### Backend
* Go
* SQLite (Database)
* Ollama (LLM Integration)

### Frontend
* Vue.js
* Vite (Build Tool)
* Marked (Markdown Renderer)
* Highlight.js (Syntax Highlighting)
